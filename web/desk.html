Strategy experiment

Run a bounded Python strategy over closed candles. Signals stay in this report and on the chart.


    

    
Language and report assumptions
Define strategy(candles). Use lists, dictionaries, comprehensions, for loops, conditions, print, sma, ema, crossed_above and crossed_below. Return a list of signals with a candle time in Unix seconds and a side of buy, sell, short or cover. Price and label are optional. The isolated worker limits each run to five seconds. The estimate pairs closing signals at candle closes, one unit per trade, before fees. Return compounds closed trades. Drawdown uses their closing equity.
