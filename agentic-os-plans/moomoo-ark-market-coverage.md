Derive tool names, routes, parameters, columns, types, pagination, metadata and summary fields from the exact Gateway package pin. Mark a route mapped only when its Gateway adapter, local fixture/replay, signed runtime path, offline saved-result rendering and source binding are present. Preserve exact decimal strings, dates, bounded pagination, metadata and summary fields. Keep unsupported routes visibly outstanding. Package the Gateway route descriptors required by offline mode and preserve the existing install and digest guards.

Use only synthetic/local fixtures. Run the affected runtime, coverage, saved-result, build and browser checks at desktop and phone sizes, plus the repository-required integration validation. Keep this lane to at most 18 changed tracked files including this PRD, at most 30 KB of new production source, and all existing per-file, chunk, $0-cost and offline constraints.
